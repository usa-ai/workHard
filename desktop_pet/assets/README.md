# WorkHardPet 素材替换说明

把你下载好的角色图片放到这个目录，或者放到 `%LOCALAPPDATA%\WorkHardPet\assets`。

推荐规则：

1. 优先使用带透明背景的 `PNG`。
2. 也可以放 `JPG`、`WEBP`、`GIF`、`BMP`。
3. 文件直接丢进目录后，重新打开桌宠就能看见。
4. 如果同名文件同时存在于 EXE 旁边的 `WorkHardPet.assets` 和本地数据目录，EXE 旁边的目录优先。
5. 不需要重新生成 EXE，也不需要重新安装 Python。

建议你保留一个默认角色文件，比如 `default.png`，后续换角色时直接替换这类文件即可。
